# 🐛 Bug Reports

This directory stores submitted bug reports from players and website visitors. Each report is saved as an individual Markdown file with its submission date, reporter details, issue description, environment info, and optional screenshots stored in `bugs/screenshots/`.

## Filename Convention
- Format: `bug-YYYYMMDD-XXX.md` (e.g., `bug-20261026-001.md`)
- Screenshots: `bugs/screenshots/bug-YYYYMMDD-XXX.png`

## Report Structure
Each Markdown report includes:
- **Report ID & Timestamp**
- **Reporter Info** (Display name, email if provided)
- **Environment** (Browser, OS, Screen resolution)
- **Detailed Bug Description**
- **Attached Screenshot** (if provided by the user)
